# Customer discovery plan

**Goal:** find out whether small-fleet operators have a charging-planning problem that existing charger software and timers
don't already solve, *before* building more features.

## Who to talk to (3–5 people)

- Fleet supervisors or dispatchers at organizations running roughly 3–10 EVs from one site (delivery, facilities, campus
  services, municipal fleets, utilities' own fleets).
- EV charging installers or electrical contractors who set up depot charging.
- Facilities managers responsible for a building that hosts fleet chargers.

Ordinary EV owners can help test **usability**, but they don't validate **fleet demand**. Record them separately.

## The five questions (ask before demoing anything)

1. Walk me through how you planned charging yesterday.
2. When was a vehicle last not ready, or charging unexpectedly expensive?
3. Which arrival, departure, energy, and tariff data do you actually know?
4. What can your existing charger software already schedule or control?
5. What would you do differently after seeing our proposed plan? *(Ask only after showing a plan built from their own
   numbers, or the sample.)*

Good follow-ups: "How do you know that?", "What did that cost you?", "Who else is involved in that decision?"
Avoid leading questions such as "Would it be useful if…?"

## Rules

- Only Aryaman arranges and conducts interviews. Nothing in this repo sends messages on anyone's behalf.
- Log only what was actually said. No invented interviews, quotes, users, or savings.
- Get permission before quoting anyone. Otherwise, paraphrase without names.
- If interviews show existing tools fully solve the problem, write that down and reconsider the product.
